# Visual Studio Code

This directory contains syntax highlightning for Visual Studio Code.

## Installation

Copy the content of this directory to your Visual Studio Code user folder:
```terminal
%USERPROFILE%\.vscode\extensions\jask\
```
or
```terminal
~/.vscode/extensions/jask/
```
and reload the windows in code in order to load the extension.
